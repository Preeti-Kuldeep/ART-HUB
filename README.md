ART HUB 🎨



ART HUB is an e-commerce platform designed for artists, buyers, and shopkeepers.



The platform allows artists to showcase and sell their paintings, buyers to browse and purchase artworks, and shopkeepers to sell art-related materials through a single integrated system.

User Registration and Login

Artist Profile Management

Installation

Clone the repository

git clone https://github.com/Preeti-Kuldeep/ART-HUB.git

Navigate to the project folder

cd ART-HUB

Create and activate a virtual environment

python -m venv env

env\\Scripts\\activate

Install dependencies

pip install -r requirements.txt

Configure the MySQL database settings in Django.

Run migrations

python manage.py migrate

Start the server

python manage.py runserver

Open the browser

http://127.0.0.1:8000
